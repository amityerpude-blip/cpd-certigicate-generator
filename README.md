# CPD Certificate Webpage

This is a clean, self-contained starter version of the CPD Certificate Generator.

## Files
- `index.html` — webpage structure
- `style.css` — responsive styling and print layout
- `script.js` — certificate generation and printing

## Use
Open `index.html` in a browser. No server or external library is required.

## Next step
This package is intended as a clean base to upload into the existing GitHub/EdgeOne project. The existing project's final design, branding, Google Form integration, QR verification, certificate numbering, and other requirements can be merged into this structure rather than repeatedly pasting large code blocks.
